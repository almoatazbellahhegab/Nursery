# Local sprint review

Owner: delivery engineer. Scope: synthetic local prototype only.

Start by double-clicking Start-Sprint-Review.cmd. Confirm the terminal prints port 3100 and Wi-Fi URLs. The server listens on all interfaces for same-network iPhone review and exposes only explicit preview routes. Never place real records in this tool.

If port 3100 is busy, close the prior review terminal. Do not terminate unrelated processes. If the browser raced server startup, refresh. If an iPhone cannot connect, verify the same Wi-Fi and the private-network Windows Firewall setting. No public tunnel is configured.

Stop with Ctrl+C. Human observations persist in review-results/uat.jsonl. Export through the portal before handoff. This is an observation log, not an authenticated approval service; sprint confirmation must come from the user in conversation and be recorded against the approved Git commit.
